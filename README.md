# Projeto_Clima - Pipeline de Dados Climáticos 🌤️

Pipeline em Python para consumo automatizado de APIs geográficas e meteorológicas com exportação estruturada em CSV.

## ⚙️ O que o projeto faz
* Extrai coordenadas de cidades via API de Geocoding.
* Coleta dados de temperatura e tempo em tempo real via API de Clima.
* Tratamento e consolidação de dados em estrutura orientada a objetos (POO).
* Exportação do dados tratado para arquivo CSV.

## 📁 Estrutura do Código
* `scripts/classes.py`: Lógica de integração com APIs e classes de tratamento.
* `scripts/main.py`: Script de orquestração e execução do pipeline.
* `arquivos/`: Dados gerados em CSV.
